01

Prepare seus dados

Abra Atributos para ajustar os bônus, Preferred List para escolher os monstros e Personalização para definir personagem, tema, dificuldade e logo. A prévia mostra como tudo aparecerá no overlay. As mudanças são salvas automaticamente.

02

Overlay via URL

  1. No topo do Bounty Studio, ligue o switch Overlay via URL. Ele começa desligado e o status muda para Sincronizado.
  2. Clique em Copiar link do OBS.
  3. No OBS, em Fontes, clique em + e escolha Navegador.
  4. Escolha Criar uma nova fonte, cole o link e defina largura 1200 e altura 360.
  5. Clique em OK. Deixe o Bounty Studio aberto durante a transmissão.

Para parar a sincronização, desligue o switch no topo. O status mostrará “Não sincronizado”.

03

Overlay via vídeo

  1. Na prévia da live, clique em Baixar vídeo e escolha onde salvar.
  2. No OBS, em Fontes, clique em +, escolha Mídia e Criar uma nova fonte.
  3. Marque Arquivo local, clique em Explorar e escolha o vídeo baixado.
  4. Marque Loop e clique em OK.

O vídeo mantém o fundo transparente. Ele é uma gravação das opções atuais; baixe outro vídeo após fazer alterações.
